# Gestion des tâches

Application web de gestion de tâches développée avec React et Vite.

## Fonctionnalités
- Ajouter une tâche avec une priorité (haute, moyenne, basse)
- Marquer une tâche comme terminée
- Supprimer une tâche
- Filtrer par statut et par priorité
- Compteurs (total, en cours, terminées)
- Sauvegarde automatique dans le navigateur (localStorage)

## Technologies
React · Vite · JavaScript (ES6) · CSS

## Lancer le projet
```bash
npm install
npm run dev
```
